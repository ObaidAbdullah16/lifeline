# State of open-source operations, 2027 (template)

Outline for the February 2027 report built from `lifeline batch`. Replace every bracket with real data.

1. **Why this matters** - three short real incidents (expired domain, hijacked action tag, deleted backups). Link sources.
2. **Method** - which projects ([N] CNCF/FOSS projects, how chosen), date of scan, Lifeline version,
   what was *not* measured (manifest checks need maintainers' input, so they are excluded).
3. **Headline numbers** (from `SUMMARY.md`):
   - Median score [x]/10; [y]% of projects have unpinned third-party actions;
     [z]% have no DMARC; [w]% have a bus factor of 1.
4. **One chart per area** - fail rate per check.
5. **What maintainers can fix in an afternoon** - the five cheapest fixes with links.
6. **Anonymity** - no project is named without its maintainers' consent.
7. **Reproduce it** - exact command, targets file, Lifeline commit SHA.
